## About

A clean and responsive personal portfolio website built with Laravel and Tailwind CSS. Showcases my projects, skills, education, and interests as a 4th year BSIT student.

## Features

- Responsive design for all devices
- Smooth scroll navigation
- Animated skill progress bars
- Project showcase section
- Contact form
- Social media links

## Tech Stack

| Technology | Purpose |
|------------|---------|
| Laravel 11 | Backend Framework |
| PHP 8.3 | Server-side Language |
| Tailwind CSS 4 | Styling |
| Blade | Templating |
| SQLite | Database |

## Getting Started

```bash
# Clone the repository
git clone https://github.com/yourusername/laro-portfolio.git

# Install dependencies
composer install
npm install

# Setup environment
cp .env.example .env
php artisan key:generate

# Run database migrations
php artisan migrate

# Start development server
composer dev
```
